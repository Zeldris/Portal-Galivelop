## Agradecimiento

Once de estas skills son de **Matt Pocock** ([mattpocock/skills](https://github.com/mattpocock/skills)). Buena parte
de esta forma de trabajar con agentes (interrogar un plan, modelar el dominio, diagnosticar, diseñar módulos
profundos, la retro) la hemos aprendido gracias a su trabajo. Cada una lleva su mención al final y la licencia MIT
se conserva en [`LICENSE-mattpocock-skills`](LICENSE-mattpocock-skills); al traerlas a otro repositorio, se
mantienen las dos cosas.

## Notas

Las copiadas se dejan tal cual (en inglés) salvo la nota «En este repositorio» al principio de las que la
necesitan. No se traen las propias del juego: `opt-ai` (IA local), `scout-updates` y las rondas de pruebas.
